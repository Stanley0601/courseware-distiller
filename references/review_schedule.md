# 复习提醒 SOP（review_schedule）

蒸馏与错题记录只是开始，按时复习才真正固化记忆。本文档规定如何把复习时间点接上宿主环境的提醒能力。

## 何时建提醒
1. 产出 `STUDY_GUIDE.md` 复习计划时（D3 / W1 / W4 三个时间点）；
2. `MISTAKES.md` 记录新错题条目时（按其复习状态流转的 D3 / W1 日期）；
3. 用户明确要求"提醒我复习"时。

## 建什么
每个复习时间点一条提醒，字段约定：
- **名称**：`【课程名】复习 · 时间点`，如"【牛顿运动定律】复习 · D3"；
- **时间**：D3/W1/W4 对应的具体日期（自蒸馏日或错题记录日起算，含当天偏移）；
- **提示词**（提醒触发时执行的动作）统一为：
  > 按 courseware-distiller 的复习流程带我复习《{课程名}》：读取课件目录 `{课件目录}/{课程名}/` 下的 `STUDY_GUIDE.md` / `MISTAKES.md` / `NOTES.md`，先给出今日应做的复习任务（线索问题自测 / 复查未掌握错题条目），逐项带我执行；完成后更新相应复习状态与 `COURSE_INDEX.md`。

## 状态流转
- 错题条目 D3 复查通过 → 把提醒改期到 W1 时间点（更新已有任务，不重复新建）；
- 条目标记"已掌握" → 删除或停用该条目的提醒；
- 增量蒸馏后 → 视情况为新覆盖章节重算 W4 时间点；
- 任何提醒改期/删除都要与 `MISTAKES.md`、`COURSE_INDEX.md` 的"待复习"字段保持一致。

## 环境适配
- **宿主有定时任务能力**（如 Loomy 的 schedule）：一次性提醒用 frequency=once + scheduledAt（ISO 日期时间，带时区）；需要固定节奏（如每晚过一遍高错率卡）可用 daily/weekly + time；
- **宿主没有定时任务能力**（降级方案）：把下次复习日期内嵌写在每个产物尾部与 `MISTAKES.md` 条目里（模板已含占位），并在每次进入该课程目录执行本技能时先读取核对——凡有到期/逾期的复习点，优先于一切新任务主动提示用户。

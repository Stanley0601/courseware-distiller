# Courseware Distiller v2.0.0

该技能把课件、讲义和讲课转写整理成可追溯的教学知识库，并在新题中复用老师已经展示过的方法。重点保存老师如何识别题型、选择方法、分步推导、检查结果，以及方法何时不适用。

## 输入能力

- 支持通过宿主工具读取 PDF、PPT/PPTX、Markdown、文本、字幕和已有转写稿。
- 原始音频只有在宿主确实提供转写能力时才能处理；否则需要先提供转写稿。
- 仅有幻灯片时，可以提取明确写出的知识和方法，不能据此还原老师未留下的口头风格和隐含推理。

## 核心产物

每门课程建立清单、来源映射、规范化文本、证据记录、方法记录、例题记录、知识索引和老师画像。笔记、卡片、导图、学习指南及错题本从这些记录派生。

讲解新题前，技能会先核对方法的识别信号、必要条件和排除条件。输出区分老师直接讲过的内容、按老师方法迁移得到的内容，以及模型补充。

## 使用示例

- “蒸馏这份课件和对应转写，重点保存老师的选法依据。”
- “用这门课老师的方法完整讲解这道题。”
- “逐步带我做，先别揭晓下一步。”
- “更新这门课，新转写纠正了上一版的方法条件。”

## 验证与打包

```powershell
powershell -ExecutionPolicy Bypass -File scripts/validate_skill.ps1
powershell -ExecutionPolicy Bypass -File scripts/package_skill.ps1 -OutputZip ..\courseware-distiller-v2.0.0.zip
```

结构校验只能检查文件、链接、模板字段和发布一致性。老师方法的忠实度需要使用真实课件、转写和留出题进行行为验收。
